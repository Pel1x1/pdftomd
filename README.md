# PDF → MD

Конвертер PDF в Markdown с окном (Windows / macOS) и консольной версией.

## Приложение
- перетащите PDF-файлы или целые папки в окно (или на иконку `PDF2MD.exe`);
- «Конвертировать» — файлы обрабатываются параллельно;
- у каждого файла: «Открыть» (просмотр + копирование) и «Сохранить»;
- внизу: «Сохранить все в папку» или «Скачать ZIP».

Режимы: **Точный** (pymupdf4llm — заголовки, таблицы, списки) и **Быстрый** (pymupdf + своя эвристика).
Сканы без текстового слоя помечаются ошибкой — для них нужен OCR.

## Сборка
| Платформа | Команда | Результат |
|---|---|---|
| macOS | `./build_mac.sh` | `dist/PDF2MD.app`, `dist/PDF2MD-mac.zip` |
| Windows | двойной клик по `build_windows.bat` (нужен Python 3.10+) | `dist/PDF2MD.exe` |
| Обе через GitHub | залить в репозиторий → Actions → **build** → Run workflow (или тег `v1.0`) | артефакты exe и .app |

Запуск из исходников: `pip install -r requirements.txt && python gui.py`.

Первый запуск на macOS: приложение не подписано — правый клик → «Открыть».
На Windows SmartScreen может предупредить: «Подробнее» → «Выполнить в любом случае».

## Консоль
`python main.py ./pdf ./md` — см. `python main.py -h`.
